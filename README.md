# Drum Arranger 0.1

Плагин для Logic Pro (AU), других DAW (VST3) и отдельное приложение. Третий в серии после Choir Arranger и Strings Arranger.

Суть в одном предложении: плагин выдаёт грув, филл или брейк под выбранный набор, готовый к перетаскиванию на дорожку, и каждого из них сотни вариантов, построенных по правилам, а не случайно.

## Что есть в 0.1

- 39 стилей в шести наборах. Рок (восьмые, шестнадцатые, полуход, райд, шаффл, томы, панк), поп (ровный, бочка в четверть, римклик, фанк, мотаун), метал (прямой, двойная бочка, галоп, скэнк, ди-бит, брейкдаун, три вида бласта), кино (гибридный пульс, ансамбль тайко, часы, трейлерные удары), оркестр (литавры и акценты, марш, остинато малого, нарастание), электроника (хаус, техно, электро, халфстеп, брейкбит, драм-н-бейс, трэп, IDM: глитч, евклидовы слои, фазовый сдвиг).
- Четыре карточки: грув, филл, брейк и фраза (грув с филлами каждые N тактов). Любую карточку можно перетащить на дорожку. Стрелки на карточке листают варианты.
- Филлы строятся из рудиментов: одиночные, двойки, парадидлы, флэмы, драги, ратамакью, линейные с бочкой, группы по три и пять. Ещё перебираются деление (от восьмых до септолей), раскладка по барабанам, форма динамики, бочка под руками и ускорение во второй половине. На сложности 7 для филла в такт получается больше тысячи девятисот разных вариантов на каждые две тысячи номеров.
- Десять видов брейков: остановка с разными затактами, только тарелки, только бочка, пауза внутри такта, раскат, полуход, такт на томах, синкопы всем набором, тарелки на слабые доли, сдвиг на восьмую.
- Полиритм: цикл ног против размера (как у Meshuggah), N ударов на такт, акценты группами через тактовую черту, метрическая модуляция, тала (филл становится тихаи с подсчётом и слогами конокола), евклидов слой.
- Любой размер: 5/8, 7/8, 9/8, 11/16 и так далее. Доли группируются по правилу 2+2+3.
- Сложность 0–10, «живость» (сдвиг от сетки и разброс силы), свинг. Всё детерминировано: одни и те же настройки дают те же ноты.
- Закрепление слоёв: низ, малый, тарелки, томы. Закреплённый слой не меняется при смене варианта.
- Ритм из MIDI: бочка встаёт на атаки басовой партии или остинато.
- Литавры строятся по тонике и доминанте в диапазоне F2–F3, отдельной дорожкой с настоящими высотами.
- Карты библиотек: GM (Logic Drum Kit Designer), MixWave Mario Duplantier, BBC SO Untuned Percussion. Чего нет в библиотеке, переводится на ближайший инструмент.
- Выход: весь набор на одной дорожке или дорожка на инструмент.
- Каждый результат проверяется на играбельность: не больше двух рук и двух ног одновременно, педаль хэта не совпадает с ударом по хэту, руки успевают перейти с барабана на барабан.
- Drum Arranger Live (AU MIDI FX): пять клавиш запускают грув, следующий вариант, филл, брейк и стоп. Сила нажатия задаёт сложность. Когда проект играет, рисунок идёт по его тактам. Сыгранное можно перетащить на дорожку.

## Как пользоваться в Logic

1. Дорожка программного инструмента, на неё AU Instruments → Teilormusic → Drum Arranger.
2. Выберите стиль, библиотеку, размер, сложность.
3. Перетащите карточку грува, филла, брейка или фразы на дорожку с барабанами.

Живой режим: слот MIDI FX → Audio Units → Teilormusic → Drum Arranger Live перед барабанной библиотекой. Клавиши от C3: грув, вариант, филл, брейк, стоп.

Если Logic не видит плагин: Logic Pro → Settings → Plug-in Manager → Reset & Rescan Selection.

## Устройство

- `core/`: движок на C++17 без JUCE. `Engine.cpp` (размеры и таблица стилей `SPECS`), `Generate.cpp` (сборка, играбельность, свинг), `Fills.cpp` (рудименты и брейки), `Poly.cpp` (полиритм и тихаи), `Midi.cpp` (карты и MIDI). Индекс стиля сохраняется в проектах: новые строки только в конец таблицы.
- `cli/drums_main.cpp`: консольная версия, `--grid` рисует результат текстом.
- `plugin/`: оболочка JUCE 8.0.4, два плагина с общим ядром.

## Проверки

```
cmake -S . -B build-core -DDRUMS_BUILD_PLUGIN=OFF -DCMAKE_BUILD_TYPE=Release && cmake --build build-core -j
build-core/drums_tests
build-core/drums_cli --style=rock8 --kind=fill --fill-variant=7 --grid
```

Тест плагина без хоста и снимки интерфейса (Linux, нужен xvfb):

```
cmake -S . -B build-ui -DDRUMS_BUILD_TESTS=ON -DCMAKE_BUILD_TYPE=Release && cmake --build build-ui --target DrumPluginTests -j2
xvfb-run -a build-ui/DrumPluginTests_artefacts/Release/DrumPluginTests docs
```

Сборка под macOS идёт в GitHub Actions: универсальный бинарник, `auval -v aumu Drum Tlrm` и `auval -v aumi DrLv Tlrm`, установщик `.pkg` и `.dmg`.

Версия записана в трёх местах: `CMakeLists.txt`, аргумент `make_installer.sh` в workflow, этот файл.
